# Inspect Token (INSP)

An ERC20 token with voting, delegation, and governance features built using OpenZeppelin.

## Features
- ERC20 Token
- ERC20 Votes (Governance ready)
- ERC20 Permit (Gasless approvals)
- ERC20 Burnable
- AccessControl (Role-based permissions)
